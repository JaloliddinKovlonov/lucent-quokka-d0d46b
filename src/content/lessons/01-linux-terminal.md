Bu darsda biz Linux terminali bilan tanishamiz. Terminal — DevOps muhandisining asosiy quroli.

## Nima o‘rganamiz

- Terminal nima va u qanday ishlaydi
- Asosiy navigatsiya buyruqlari
- Fayl va papkalar bilan ishlash

## Asosiy buyruqlar

Joriy papkani ko‘rish:

```bash
pwd
```

Papkadagi fayllar ro‘yxati:

```bash
ls -la
```

Papkaga o‘tish:

```bash
cd /home/user/loyiha
```

## Uyga vazifa

Terminalda yangi papka yarating va uning ichiga kiring. Keyingi darsda fayllar bilan ishlashni davom ettiramiz.
